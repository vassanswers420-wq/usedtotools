Edit PDFs Without Installing Software

Most PDF editors require a desktop installation or a paid subscription. This tool runs entirely in your browser using PDF.js — the same technology trusted by Firefox and Google Chrome. There's nothing to install, and it works on Windows, Mac, Linux, iOS, and Android.

All annotation rendering happens client-side using HTML5 Canvas, so performance is fast and your document stays completely private. Your PDF is never uploaded to any external server or cloud service.

Privacy & Security

Your files are processed entirely within your own browser. When you open a PDF, it is read by the JavaScript engine on your device and rendered to an HTML5 canvas — no bytes are transmitted to any external server.

This makes the editor ideal for sensitive documents: contracts, medical records, financial statements, or personal files you would never want to upload to a cloud service.
